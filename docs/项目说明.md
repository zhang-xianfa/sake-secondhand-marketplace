# 项目结构说明

## 应用层 `app/`

### `app/routes/` —— 蓝图（Blueprint）

每个文件对应一个功能模块的路由与视图逻辑：

| 文件 | 职责 |
|---|---|
| `admin.py` | 管理员后台管理功能（分类、商品、留言删除） |
| `auth.py` | 用户认证相关功能（注册、登录、登出） |
| `chat.py` | 用户私信聊天功能 |
| `goods.py` | 商品管理（发布、详情、编辑、删除、收藏、留言、回复、点赞、上下架、交易发起） |
| `index.py` | 网站首页商品展示与筛选 |
| `notification.py` | 用户通知消息中心（查看、标记已读、回复） |
| `payment.py` | 订单支付相关功能（创建订单、模拟支付） |
| `profile.py` | 用户个人信息编辑与头像上传 |
| `user_center.py` | 用户个人中心（我的发布、我的留言、我的收藏） |

### `app/models.py`

定义全部数据库模型（`User`、`Goods`、`Message`、`Order` 等）及其关系。

### `app/__init__.py`

应用工厂：创建 Flask 应用实例、初始化数据库 / 登录管理器 / SocketIO，
注册全部蓝图，并注册 WebSocket 连接与断开事件处理器。

## 迁移 `migrations/`

使用 Alembic 管理数据库迁移，`versions/` 下存放具体的迁移版本脚本。

## 静态资源 `static/`

| 目录 | 内容 |
|---|---|
| `css/` | 样式表 |
| `png/` | 通用图片（图标等） |
| `uploads/` | 用户上传的文件 |

## 模板 `templates/`

全部页面模板，通过 Jinja2 渲染。`base.html` 为基础布局模板，其余页面继承它。

## 入口文件

| 文件 | 说明 |
|---|---|
| `config.py` | 应用程序配置（数据库 URI、密钥、文件上传路径等） |
| `manage.py` | 数据库迁移脚本入口（配合 Flask-Migrate 使用） |
| `run.py` | 应用程序启动文件，运行 Flask 应用与 SocketIO 服务器 |
| `.flaskenv` | Flask 环境变量配置 |
| `requirements.txt` | 项目依赖库列表 |
